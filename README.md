# QA_internship_avito

## Структура репозитория
- Task 1
  - BUGS_TASK_1.md - файл с описанием найденных багов

- Task 2
  - TESTCASES.md - тесткейсы к заданию 2.2
  - pom.xml, .gitignore, .idea, src/test/java - файлы проекта с автотестами к заданию 2.2 (src/test/java содержит решение задачи на языке Java, разделенное на классы по паттерну PageObject)
  - BUGS.md - файл с описанием найденных багов

- README.md - описание проекта и инструкция

## Инструкция для запуска автотестов

1) Установить IDEA от JetBrains с официального сайта
2) Установить git, java
3) Клонировать репозиторий git clone https://github.com/lukajin01/QA_avito_2025.git
4) Установить все зависимости через файл pom.xml в среде разработки
5) Запустить автотест в классе CheckoutTest
